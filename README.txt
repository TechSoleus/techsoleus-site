TECHSOLEUS — FREE STATIC WEBSITE

This is a no-subscription starter build for the TechSoleus website.

Files:
- index.html
- style.css
- script.js

No paid libraries, no AI credits, no database and no backend are required.

The design intentionally uses CSS-made visuals instead of paid/credit-based image generators.
You can replace the placeholder project visuals later with your own screenshots.

Recommended free deployment:
1. Create a free GitHub account.
2. Create a PUBLIC repository named techsoleus-site.
3. Upload these three files.
4. In GitHub: Settings → Pages → Deploy from branch → main → /root.
5. GitHub will give you a free github.io URL.

Alternative:
Cloudflare Pages can deploy static HTML and gives a free pages.dev address. It is also suitable for this project.

Important:
A custom .com domain is normally not free. We will NOT buy one yet.
Use the free URL while validating the business and pitching clients.
